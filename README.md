# Foundation AI Team

A Discord bot that gives the Foundation server a five-agent AI council.

## Commands

- `!team` — list the live AI roles.
- `!council <mission>` — ask all five agents to collaborate.
- Mention `@Foundation` — talk directly with Atlas.

## Required environment variables

- `DISCORD_TOKEN`
- `OPENAI_API_KEY`
- `OPENAI_MODEL` (optional; defaults to `gpt-5-mini`)

Run with `npm start`.
